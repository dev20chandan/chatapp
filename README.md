# chatapp

Full-stack real-time WhatsApp clone with Expo (React Native) frontend and NestJS (Socket.IO) backend.

## Project Structure
- `whatsapp-clone/` - Expo React Native mobile & web app
- `whatsapp-backend/` - NestJS WebSocket Gateway backend server

## Getting Started

### Backend
```bash
cd whatsapp-backend
npm install
npm run start:dev
```

### Frontend (Mobile App)
```bash
cd whatsapp-clone
npm install
npm start
```
